# Python Advanced - File Handling

## Descripción

Este proyecto introduce los mecanismos de entrada/salida (I/O) de Python,
con enfoque en la manipulación de archivos. Se exploran las operaciones
fundamentales para abrir, leer, escribir y añadir contenido a archivos,
así como la importancia de gestionar correctamente los recursos de archivo
mediante la sentencia `with`.

Estos conceptos son esenciales para aplicaciones del mundo real, donde los
programas a menudo necesitan almacenar resultados, procesar datos externos
o comunicarse con otros sistemas. Una comprensión sólida de las operaciones
de I/O también apoya el aprendizaje futuro en áreas como bases de datos,
APIs y canalizaciones de procesamiento de datos.

Se presta especial atención a casos límite que los principiantes suelen
subestimar: codificación de archivos (UTF-8), archivos faltantes y una
gestión inadecuada de los recursos, que pueden provocar errores sutiles o
pérdida de datos si se ignoran.

## Objetivos de aprendizaje

- Cómo abrir un archivo
- Cómo escribir texto en un archivo
- Cómo leer el contenido completo de un archivo
- Cómo leer un archivo línea por línea
- Cómo mover el cursor en un archivo
- Cómo asegurarse de que un archivo se cierre después de usarlo
- Qué es la sentencia `with` y cómo usarla

## Requisitos

- Todos los archivos se interpretan/compilan en **Ubuntu 20.04 LTS**
  usando `python3` (versión **3.8.5**).
- Todos los archivos deben terminar con una nueva línea.
- La primera línea de todos los archivos debe ser exactamente:
  `#!/usr/bin/env python3`
- El archivo `README.md`, en la raíz de la carpeta del proyecto, es
  obligatorio.
- El código debe cumplir con `pycodestyle` (versión **2.7.\***).
- Todos los archivos deben ser ejecutables (`chmod +x`).
- La longitud de los archivos se comprobará con `wc`.
