## 📚 Proyecto: `classes_and_object_model`

Introducción al **modelo de objetos de Python**: definición de clases, creación de instancias, gestión de estado, encapsulamiento y métodos especiales.

### 🎯 Objetivos de aprendizaje

Al completar este proyecto, serás capaz de:

- Explicar la diferencia entre una **clase** y una **instancia**
- Crear clases que modelen entidades simples
- Definir e inicializar atributos de instancia usando `__init__`
- Implementar métodos de instancia que operen sobre el estado del objeto
- Aplicar principios básicos de **encapsulamiento**
- Validar entradas al construir objetos
- Controlar el acceso a atributos internos
- Implementar representaciones en cadena de objetos usando métodos especiales (`__str__`, `__repr__`)
- Diseñar clases simples que modelen conceptos del mundo real

## 🛠️ Requisitos generales

Todos los archivos de este proyecto cumplen con:

- **Entorno de evaluación:** Ubuntu 20.04
- **Versión de Python:** Python 3.8
- **Ejecutables:** todos los archivos `.py` son ejecutables (`chmod +x`)
- **Shebang:** la primera línea de cada archivo es `#!/usr/bin/env python3`
- **Nueva línea final:** todos los archivos terminan con una nueva línea
- **Estilo:** código conforme a **PEP8**
- **Documentación:** todos los módulos, clases y funciones incluyen **docstrings** claros y concisos
- **Dependencias:** sin bibliotecas externas (solo la librería estándar)
